# Everything Burger

Static shop site with a Stripe Checkout backend. Runs locally on Node, deploys
free to Cloudflare Workers.

## Why there is a backend at all

Everything in `shop/js/` runs in the shopper's browser and can be edited with
devtools, so prices can never be trusted from there. The cart only ever sends
product ids, sizes, and quantities. Prices are looked up server-side in
`backend/shared/catalog.js`, which is also the only place the Stripe secret key
exists.

## Layout

Everything the browser downloads lives at the top level. Everything that
touches Stripe lives under `backend/` and is never served to visitors.

| Path | Purpose |
|---|---|
| `index.html`, `shop/`, `gallery/`, `about/`, `assets/` | the public site |
| `shop/**-data.js` | product definitions, the only place to edit products |
| `backend/shared/` | checkout logic used by both runtimes |
| `backend/worker/index.js` | Cloudflare entry point (production) |
| `backend/server/` | Express entry point (local development) |
| `backend/scripts/` | build steps |
| `wrangler.toml` | Cloudflare deployment config |

`backend/shared/catalog-data.js` and `dist/` are generated by `npm run build`.
Don't edit them by hand.

## Local development

```bash
npm install
cp .env.example .env      # then fill in your Stripe test keys
npm start
```

Open http://localhost:3000. Opening the HTML files directly will not work,
because checkout needs the API on the same origin.

To test webhooks, in a second terminal:

```bash
stripe listen --forward-to localhost:3000/api/webhooks/stripe
```

Copy the `whsec_…` it prints into `STRIPE_WEBHOOK_SECRET` and restart the
server. Pay with test card `4242 4242 4242 4242`, any future expiry, any CVC.
Paid orders append to `backend/server/var/orders.jsonl`.

To run the Cloudflare version locally instead:

```bash
cp .env .dev.vars         # wrangler reads secrets from .dev.vars
npm run cf:dev            # http://localhost:8787
```

Set `PUBLIC_BASE_URL=http://localhost:8787` inside `.dev.vars`.

## Deploying to Cloudflare (free)

1. Push this repo to GitHub. `.env`, `.dev.vars`, and `dist/` are gitignored
   and must stay that way.

2. Create a free Cloudflare account, then log in:

```bash
npx wrangler login
```

3. Set `PUBLIC_BASE_URL` in `wrangler.toml` to the URL you will actually serve.
   With no custom domain that is `https://everything-burger.<your-subdomain>.workers.dev`,
   which Cloudflare shows you after the first deploy. Deploy once, copy the
   printed URL into `wrangler.toml`, then deploy again so Stripe's redirects
   point at the right place.

4. Upload the secrets. These are stored by Cloudflare, never in the repo:

```bash
npx wrangler secret put STRIPE_SECRET_KEY
npx wrangler secret put STRIPE_WEBHOOK_SECRET
```

5. Deploy:

```bash
npm run cf:deploy
```

6. In the Stripe Dashboard, go to Developers → Webhooks → add an endpoint at
   `https://your-url/api/webhooks/stripe`, subscribe it to
   `checkout.session.completed`, reveal its signing secret, and store it with
   `wrangler secret put STRIPE_WEBHOOK_SECRET`. This is a different value from
   the one the Stripe CLI prints locally.

Redeploy any time with `npm run cf:deploy`. The build regenerates the catalog
from `shop/**-data.js`, so adding a product is an edit plus a deploy.

## Going live

Test keys never move real money. When ready:

- Switch off test mode in Stripe and complete their account activation
- Replace the secret with the live key: `npx wrangler secret put STRIPE_SECRET_KEY`
- Create a live-mode webhook endpoint and store its signing secret the same way
- Confirm `PUBLIC_BASE_URL` matches your real domain over HTTPS

Stripe charges roughly 2.9% + 30¢ per card payment. Hosting stays free within
Cloudflare's 100,000 requests per day.

## Orders

On Cloudflare there is no writable disk, so paid orders are logged to
`wrangler tail` output rather than a file. The durable record is the Stripe
Dashboard, which stores every payment with the shipping address and a `cart`
metadata field describing what was bought. Enable Stripe's email notifications
to get told about each sale.

## Configuration

Non-secret settings live in `[vars]` in `wrangler.toml` for production, and in
`.env` locally.

| Variable | Default | Meaning |
|---|---|---|
| `PUBLIC_BASE_URL` | — | origin used for Stripe redirects |
| `CURRENCY` | `usd` | Stripe currency code |
| `SHIPPING_CENTS` | `800` | flat shipping, `0` for free |
| `MAX_QTY_PER_LINE` | `20` | per-line quantity cap |
| `MAX_CART_LINES` | `30` | distinct items per order |
| `ALLOWED_SHIPPING_COUNTRIES` | `US,CA` | Stripe country allowlist |
